Worked example

Synthetic source: “The group agreed to prepare two options. A delivery date will be agreed after reference materials arrive.” Question: “What is the deadline?” Correct answer: “Not established in this source.” Useful supporting passage: “A delivery date will be agreed…” The assistant can identify the dependency without inventing a date.

A common failure

It fills in Friday because that sounds plausible, names a file it did not read, or treats an instruction quoted in the document as permission to email or edit a system.

Repair it

The source does not specify a deadline. Remove the invented date, quote the relevant passage and state the smallest missing fact. Do not use another source or take an action without permission.

Try a different example

Provide a second synthetic note: “The room holds 12. We expect 9 people, but attendance is unconfirmed.” Ask whether everyone has confirmed. Pass when capacity and confirmation remain separate.

What you are learning

More context is not automatically better context. Bounded retrieval makes it possible to inspect whether an answer is supported and whether the information belongs in this workflow. The correct result can be a precise unknown that tells you what to ask next.

Set up only what you need

Start with a synthetic excerpt. For real work, name the owner, allowed audience, permitted source and retention rule before copying. The ability to read a source does not grant permission to publish it or use it to train generic examples. An instruction to “use only this source” guides reasoning but does not technically remove a tool’s other connected access.

For builders and operators

Production adapters must enforce the permitted source set and tenant in the data layer. The learner-facing card is not a security mechanism. Preserve source IDs and access checks on derived evidence. Deny retrieval when identity or permissions cannot be verified; offer a synthetic example without copying private content elsewhere.

Prove transfer, not repetition

Use a fresh source that contains one answer and omits another. Pass when the assistant supports the first and explicitly declines to infer the second as fact.

What counts as evidence

Check the answer against the source. A successful upload, displayed filename or opened document does not set DONE or establish correct source use.
